# Contribuer à Zap Client ⚡

Merci de vous intéresser au développement de **Zap Client** ! Les contributions de la communauté (code, traductions, signalement de bugs, suggestions) sont les bienvenues.

---

## 🐞 Signaler un bug

1. Vérifiez dans les [Issues ouvertes](https://github.com/ac-zap/Zap.CC/issues) que le problème n'a pas déjà été signalé.
2. Si le problème est nouveau, créez une nouvelle issue en incluant :
   - Votre système d'exploitation (Windows 10/11, distribution Linux, macOS).
   - Les étapes précises pour reproduire le bug.
   - Les journaux d'erreurs (logs) ou captures d'écran le cas échéant.

---

## 💡 Proposer une amélioration

Les idées de nouvelles fonctionnalités sont les bienvenues ! Ouvrez une issue avec l'étiquette **Enhancement** pour décrire votre proposition et en discuter avant d'entamer le développement.

---

## 🛠️ Développement & Pull Requests

1. **Forkez** le dépôt : [https://github.com/ac-zap/Zap.CC](https://github.com/ac-zap/Zap.CC)
2. Créez une branche dédiée à votre fonctionnalité ou correctif :
   ```bash
   git checkout -b feature/ma-fonctionnalite
   ```
3. Assurez-vous que votre code compile proprement et respecte le formattage Rust :
   ```bash
   cargo fmt --check
   cargo clippy
   ```
4. Committez vos modifications avec un message clair et descriptif.
5. Ouvrez une **Pull Request** sur la branche principale du dépôt officiel.
